# CodeAlpha_LanguageTranslationTool

A simple Language Translation Tool developed using Python and Streamlit. This application allows users to translate text between multiple languages and listen to the translated output using Text-to-Speech functionality.

## Features

* Translate text between multiple languages
* User-friendly Streamlit interface
* Source and destination language selection
* Real-time translation using Google Translator
* Text-to-Speech audio playback for translated text

## Technologies Used

* Python
* Streamlit
* deep-translator
* gTTS (Google Text-to-Speech)

## Supported Languages

* English (en)
* Hindi (hi)
* Telugu (te)
* French (fr)
* Spanish (es)

## Project Workflow

1. Enter text in the input box.
2. Select source language.
3. Select destination language.
4. Click the Submit button.
5. View the translated text.
6. Click Play Audio to listen to the translated output.

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
